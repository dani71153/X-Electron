# Coding rules

Escribe código simple, explícito y mantenible.

## Nivel
- Asume programador junior/intermedio.
- Evita abstracciones innecesarias.
- Explica cambios complejos en comentarios breves.

## Estilo
- Nombres descriptivos.
- Funciones pequeñas.
- No refactorizar arquitectura sin permiso.
- Mantener sintaxis clara antes que elegante.

## Arquitectura
- Respetar estructura actual del proyecto.
- Separar lógica, datos, UI y configuración.
- Antes de cambiar muchos archivos, proponer plan.

## Validación
- Ejecutar tests/linter si existen.
- Mostrar resumen de archivos modificados.
